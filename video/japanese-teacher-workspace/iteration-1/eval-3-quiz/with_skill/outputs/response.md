# 🎯 기초 실력 확인 퀴즈 (全5問)

---

### 【1문제】 읽기(ふりがな) 맞추기

다음 한자의 읽기를 히라가나로 써보세요.

**日本語**

- ① 日 → (          )
- ② 本 → (          )
- ③ 語 → (          )

> **힌트:** 이 세 글자를 합치면 "일본어"라는 뜻이에요!

<details>
<summary>정답 보기</summary>

- ① にち
- ② ほん
- ③ ご

합치면: **にほんご** (일본어)

</details>

---

### 【2문제】 한국어 → 일본어 변환

다음 한국어를 일본어 히라가나로 써보세요.

**"감사합니다"를 일본어로 하면?**

- (                              )

<details>
<summary>정답 보기</summary>

**ありがとうございます**

</details>

---

### 【3문제】 빈칸 채우기

다음 문장의 빈칸에 알맞은 조사를 넣어보세요.

**わたし（　　）がくせいです。**
(わたし＿がくせいです)

→ "나는 학생입니다."

- ① が
- ② は
- ③ を
- ④ に

<details>
<summary>정답 보기</summary>

**② は**

わたし**は**がくせいです。(저는 학생입니다.)

**は** (wa)는 주제를 나타내는 조사예요. "~는/~은"에 해당해요.

</details>

---

### 【4문제】 읽기 맞추기

다음 일본어의 올바른 읽기(히라가나)를 고르세요.

**食べる**

- ① たべる
- ② しょくべる
- ③ くべる
- ④ のべる

<details>
<summary>정답 보기</summary>

**① たべる**

食べる(たべる) = 먹다

</details>

---

### 【5문제】 한국어 → 일본어 변환

다음 인사말을 일본어 히라가나로 써보세요.

**"안녕하세요" (아침 인사)를 일본어로 하면?**

- (                              )

<details>
<summary>정답 보기</summary>

**おはようございます**

아침 인사: おはようございます (안녕하세요/좋은 아침이에요)

참고로:
- 낮 인사: こんにちは
- 저녁 인사: こんばんは

</details>
